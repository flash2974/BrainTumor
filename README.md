# BrainTumor
Brain tumor recognition from MRI images, with some models i've built :
- CNN
- ResNet
- Vision Transformer (ViT)

All of them built with TensorFlow/Keras. 
I used two different datasets : 
- No. 1 : [Yes/No](https://www.kaggle.com/datasets/navoneel/brain-mri-images-for-brain-tumor-detection) : Only yes and no detection
- No. 2 : [4 categories](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset). Able to recognize 4 types of tumors :
    - glioma
    - meningioma
    - no tumor
    - pituitary
